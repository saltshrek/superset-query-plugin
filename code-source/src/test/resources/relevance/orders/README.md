# Orders

Daily orders and products, built on `cleaned_sales_data` like
[sales](../sales/README.md), but grouped by day. Background:
<https://www.richardtwatson.com/open/Reader/ClassicModels.html>

| Column      | Meaning                  |
|-------------|--------------------------|
| `orderdate` | When the order was placed |
| `sales`     | Line total, in dollars    |
